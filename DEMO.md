# Demo

Hey there! Since Minamo is a self-hosted, S3-compatible storage backend service, we don’t host a public live demo.

You can easily set up your own instance in less than a minute. Check out [USAGE.md](USAGE.md) for quick instructions on configuring and running Minamo on your own server.

> **To the Hack Club Shipwrights Team:** Minamo is a self-hosted S3-compatible storage backend without a web UI, so hosting a public instance would introduce unnecessary risks such as data leaks and abuse. It would also be quite expensive for me to operate a free public instance.
