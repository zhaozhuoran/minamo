# Demo

Hey there! Since Minamo is a self-hosted S3-compatible storage backend service, we don’t host a live online demo.

We don’t provide a public preview server or a demo video for the same reason: neither can meaningfully demonstrate Minamo’s actual design and architecture, while a demo video can also be easily fabricated and therefore provides limited confidence in how the service actually works.

You can easily set up your own instance in less than a minute. Check out USAGE.md for quick steps on configuring and running Minamo on your server.
